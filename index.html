HMC（ハードウェア管理コンソール）

PSW: -

障害シナリオ（次の「最初から」で有効）

チェックしたシナリオは、マシンの状態（前回の停止状態・接続されている装置など）として次の開始時に反映されます。

IPL 手順（本番 SYSA）

      
    
        
  1. HMC: ロードアドレス 0A80、ロードパラメーター 0A8200M1（IODF/IPLPARM は 0A82、LOAD00、メッセージ表示・プロンプトなし、標準核）
    2. 
        
  2. パラメーターを変える必要があるときは IMSI を A（両方プロンプト）にする: 0A8200A1
    3. 
        
  3. IEA347A → Enter（SYSCATLG）または R 00,xx
    4. 
        
  4. IEA101A → Enter（IEASYS00）または R 00,SYSP=01 など
    5. 
        
  5. JES2 の $HASP426 → R nn,WARM（通常）。$HASP400 が出たら $S
    6. 
        
  6. S VTAM → S TCPIP → S TSO
    7. 
      

      
停止手順

      
    
        
  1. P TSO（ユーザーが残っていれば IKT010D に SIC）
    2. 
        
  2. P TCPIP
    3. 
        
  3. Z NET（VTAM 停止。急ぐ場合 Z NET,QUICK）
    4. 
        
  4. $P（イニシエーター drain）→ $DA / D A,L で残りのジョブを確認。終了を待つか C jobname
    5. 
        
  5. $P JES2（$HASP607 が出たら $HASP608 の内容を片付けて再入力）
    6. 
        
  6. Z EOD（IEE334I）
    7. 
        
  7. V XCF,SYSA,OFFLINE → IXC371D に R nn,SYSNAME=SYSA（または HMC からシステムリセット）
    8. 
      

      
出典: z/OS MVS System Commands p.2-7、JES2 Commands p.30-39。手順はこのシミュレータ環境用に簡略化した例です。

    

    

      
使えるコマンド

      
    
        
  • R id,text / REPLY id,text 応答（NIP 中は Enter で空応答）
    • 
        
  • D T 時刻、D A,L 活動中ジョブ、D R,L 応答待ち一覧
    • 
        
  • S name（JES2 / VTAM / TCPIP / TSO）、S JES2,PARM='WARM,NOREQ'
    • 
        
  • P name、Z NET[,QUICK]、Z EOD
    • 
        
  • C name[,A=asid]、FORCE name[,ARM][,A=asid]
    • 
        
  • $S $P $DA $DU $D JES2 $P JES2[,ABEND|,TERM|,ABEND,FORCE]
    • 
        
  • V XCF,SYSA,OFFLINE
    • 
        
  • WAIT n（シミュレータ独自: n 分経過させる）
    •
