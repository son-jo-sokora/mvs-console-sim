# できること・できないこと

MVS コンソール シミュレータ（z/OS 3.2・システム SYSA・JES2）で体験できることと、できないことの一覧です。
これは学習用のシミュレーションで、本物の z/OS ではありません。メッセージの番号や文面は z/OS 3.2 のマニュアルと照合していますが、実機と異なる場合があります。マニュアルに記載が見つからなかった挙動の扱いは [decisions.md](decisions.md) にまとめています。

---

## できること

### HMC（ハードウェア管理コンソール）

| 機能 | 内容 |
|---|---|
| LOAD | ロードアドレスとロードパラメーター（8桁）を入れて IPL する。1〜4桁目（IODF 装置）・5〜6桁目（LOADxx）・7桁目（IMSI）・8桁目（代替核）を桁ごとに検査する |
| システムリセット | 稼働中・待機状態・ハング中のシステムを止める。JES2 を止めずにリセットすると、次の IPL でチェックポイントのロックが残る |
| PSW の表示 | 無効待機状態になると PSW と待機状態コードを表示し、押すと原因と対処の解説が出る |
| 待機状態コード | 6種類：00F（IPL テキストなし）、0B3（LOAD パラメーターの装置番号の誤り）、088（LOADxx がない・核の指定誤り）、0B1（IODF がない）、05F（マスターカタログの誤り）、0A2（sysplex からの切り離し） |

### IPL（初期化中の応答）

| 機能 | 内容 |
|---|---|
| IMSI | 8種類（. A C D M P S T）。情報メッセージの表示・非表示と、マスターカタログとシステムパラメーターを聞くかどうかが変わる |
| マスターカタログ | IEA347A に Enter（SYSCATLG）または 2 文字（SYSCATxx）で応答 |
| システムパラメーター | IEA101A への応答。SYSP=（IEASYS00・01・02）、CLPA、CONT による継続、OPI=NO のパラメーター（IEA107I）、構文の誤り（IEA321I）、存在しないメンバー（IEA301I・IEA324I・IEA336A） |
| 装置の問題 | ラベルのない DASD（IEA311I）、応答しない共用 DASD（IEA120D）、ボリューム名の重複（IEA213A）、SYSRES の重複（IEA214A） |
| 時刻の確認 | IEA888A への応答（U、または DATE=…,CLOCK=…） |
| sysplex | 停止済みシステムの記録が残っているとき（IXC404I・IXC405D の I / J / R、IXC207A） |

### JES2

| 機能 | 内容 |
|---|---|
| 起動 | $HASP426 への開始オプション（WARM・COLD・FORMAT・NOREQ など）。`S JES2,PARM='…'` での起動も可。オプションの誤りは $HASP427 |
| コールドスタート | $HASP436・$HASP441 の確認。スプール上のジョブと出力が消える |
| チェックポイントのロック | 前回の異常終了で残ったロック（$HASP479・$HASP454）。初回起動（チェックポイント未初期化）の流れ |
| 処理の開始・休止 | `$S`、`$P`（$HASP099） |
| 停止 | `$P JES2`（作業が残っていれば $HASP607・$HASP608）、`$P JES2,ABEND`、`$P JES2,ABEND,FORCE`（$HASP553）、`$P JES2,TERM`（$HASP9157） |
| 表示 | `$DA`、`$DU`、`$D JES2` |
| ジョブの操作 | `$DJ` / `$HJ` / `$AJ` / `$CJ`（ジョブ名 'name' または番号で指定） |

### タスクの起動・停止

| 機能 | 内容 |
|---|---|
| 起動 | `S VTAM`（`S NET`）、`S TCPIP`、`S TSO`。存在しないプロシージャーは IEFC612I |
| 停止 | `P TSO`（利用者が残っていれば IKT010D に SIC / FSTOP）、`P TCPIP`、`Z NET`・`Z NET,QUICK`（VTAM） |
| 順序の制約 | JES2 が動いていないと VTAM・TCP/IP・TSO を起動できない。VTAM がないと TSO を起動できない。TSO が動いていると通常の `Z NET` は TSO の停止を待つ |

### ジョブの操作

| 機能 | 内容 |
|---|---|
| 取り消し | `C jobname`（IEE301I・IEF450I S222）、同名ジョブは `A=asid` で指定（IEE842I） |
| 強制終了 | `FORCE jobname`（CANCEL の前は IEE838I）、取り消し不可のジョブは `FORCE jobname,ARM`（IEE841I・IEE838I） |
| データセットの奪い合い | DSN と DISP から判定し、待つジョブに IEF861I・IEF863I・IEF099I を出す。使用中のジョブが終わると自動で先へ進む |
| 実行時間 | バッチジョブは「名前と実行にかかる分」で動く。時間を進めると終わる |

### コンソール・その他のコマンド

| 機能 | 内容 |
|---|---|
| 応答 | `R nn,text` / `REPLY nn,text`。番号違い（IEE704I）、応答待ちなし（IEE701I）、区切りの誤り（IEE702I） |
| 表示 | `D T`（時刻）、`D A,L`（活動中のタスク）、`D R,L`（応答待ちの一覧） |
| HALT EOD | `Z EOD`（IEE334I） |
| sysplex からの切り離し | `V XCF,SYSA,OFFLINE`（IXC371D に SYSNAME=SYSA で応答 → 待機状態 0A2 理由 004） |
| 時間を進める | `WAIT n`、または「+1分」「+5分」ボタン（シミュレータ独自） |
| 誤ったコマンド | 綴りの誤りなどは IEE305I |

### SYSLOG

| 機能 | 内容 |
|---|---|
| 記録 | すべてのメッセージとコマンドを時刻・ジョブ番号つきで記録する。IMSI でコンソールに出なかった初期化中のメッセージも残る |
| 表示と検索 | コンソールの上の「SYSLOG」タブで、メッセージ ID・ジョブ名・文字列で検索できる（一致した部分を強調表示） |

### 解説と採点

| 機能 | 内容 |
|---|---|
| メッセージの解説 | コンソールの行を押すと、日本語の解説と出典（マニュアル名・PDF のページ）を表示する。シミュレータが出す 91 種類のメッセージ ID と 6 種類の待機状態コードすべてに解説がある |
| 停止手順の採点 | JES2 停止 → HALT EOD の順序、VTAM の停止、`$P JES2,ABEND` を使わなかったか、停止手順なしのリセットをしなかったか |

### 練習の題材

| 題材 | 内容 |
|---|---|
| 障害シナリオ | 15 種類（IPL 9、JES2 2、停止 4）。チェックして最初から始める。「ランダム」で内容を伏せて 1〜3 個仕込める |
| 手順例 | 16 本（正常系 3、停止時の対応 4、IPL 時の障害対応 9）。画面出力はシミュレータで実際に流して作っている。各手順からシミュレータで試せる |
| 演習シナリオ | 17 本。基本（X1〜X5）、jcl-terminal との連携（XL1〜XL4）、SYSLOG 調査（XS1〜XS5）、複合（C1〜C3）。答えを伏せて挑戦し、演習ごとの採点項目で採点する |
| 演習の仕組み | 決まった操作や時刻に起きる出来事（連絡・ジョブの投入・障害の追加・ハング）、「前のシフト」の記録（SYSLOG にだけ残る）、事象ごとの診断の報告（原因の選択肢と根拠のメッセージ ID）、段階ごとの採点 |

### jcl-terminal との連携モード

| 機能 | 内容 |
|---|---|
| つなぎ方 | 同じサイトで開いた [jcl-terminal](https://github.com/son-jo-sokora/jcl-terminal) の別タブとつながる。jcl-terminal は SYSA の TSO 利用者 USER01 になる |
| ジョブの投入 | jcl-terminal で `SUB` したジョブが、シミュレータの JES2 で実行される（$HASP100 → $HASP373 → $HASP395）。JCL エラーのジョブは実行されずに終わる（IEFC452I・$HASP396） |
| 実行のタイミング | `$S` の前・`$P` の後は入力キューで待つ。データセットを使用中なら IEF099I で待つ |
| ジョブの問い合わせ | 練習用プログラム OPRASK の問い合わせ（OPR001A）がシミュレータのコンソールに出て、そこで応答する |
| 保留・取り消し | `$DJ` / `$HJ` / `$AJ` / `$CJ`、`C jobname`。jcl-terminal の SDSF の行コマンド H / A / C もシミュレータに送られる |
| 停止・再起動の影響 | `P TSO` で USER01 がログオフされる。実行中にリセットするとウォームスタートで再実行される（$HASP406）。コールドスタートでは連携ジョブと出力が消える |

### テスト

| 機能 | 内容 |
|---|---|
| 単体テスト | 166 件（エラー 86、連携 18、手順例 16、演習の模範解答 17、誤答 29）。ブラウザの `tests/run.html` か `node tests/run-tests.js` |
| 結合テスト | 本物の jcl-terminal を相手に 25 件（`tests/link-e2e.html`） |

## できないこと

### 対象外の構成・製品

| 項目 | 備考 |
|---|---|
| JES3 | JES2 のみ |
| 複数メンバーの MAS（JES2 の多重構成） | SYSA の1メンバーのみ |
| sysplex の相手システム（SYSB）の操作 | XCF の応答だけ模擬。SYSB 側に出る IXC102A・IXC402D などへの応答はできない |
| カップリング・ファシリティ、構造体の操作 | なし |
| Db2・CICS・IMS・MQ・RMF などのサブシステム | なし |
| 実機・エミュレーターとの接続 | なし |

### 対象外の操作・コマンド

| 項目 | 備考 |
|---|---|
| 装置の操作（`V dev,ONLINE/OFFLINE`）・装置の表示（`D U`） | IPL 中に OFFLINE にした装置を戻す操作はできない |
| `D IPLINFO`・`D M`・`D C` などのほかの表示コマンド | 使える表示は `D T`・`D A,L`・`D R,L` と JES2 の `$DA`・`$DU`・`$D JES2`・`$DJ` |
| ダンプの取得（スタンドアロンダンプ、`DUMP`、`SLIP`） | なし |
| SMF・ログの切り替え（`I SMF` など） | なし |
| VTAM のノード操作（`V NET`）、TCP/IP の表示・変更 | 起動と停止のみ |
| TSO 利用者の個別の取り消し（`C U=`） | `P TSO` の IKT010D でまとめて終了させる |
| コンソールの設定（`K` コマンド、MPF、複数コンソール） | コンソールは1台（MSTCON） |
| RACF・コンソールへのログオン | なし |
| `QUIESCE`、`$E`（JES2 のリセット・再起動系） | なし |
| オペレーター側の SDSF 画面 | ジョブの状態はコマンドと SYSLOG で確認する（SDSF は jcl-terminal 側にある） |

### 再現していない挙動

| 項目 | 備考 |
|---|---|
| PARMLIB メンバーの中身の編集 | LOADxx・IEASYSxx・CONSOLxx などは固定。IEA101A で受け付けたパラメーターのうち、動作に反映するのは SYSP・CLPA など一部 |
| 上記 6 種類以外の待機状態コード | マシンチェックなどハードウェア起因の障害も扱わない |
| ハングの原因 | ハングは出来事として起きるだけで、原因を示すメッセージは出ない |
| バッチジョブの中身の実行（連携していないとき） | 名前と実行時間だけの模擬。JCL の中身を実行するのは連携モードの jcl-terminal |
| 実時間の経過 | 時間はオペレーターの操作（コマンド・WAIT・ボタン）でしか進まない |
| SYSLOG の正確なレコード形式 | ルーティングコードなどは再現しない。並びは jcl-terminal の SYSLOG 画面と同じ簡略形 |
| 一部の対話 | $HASP454 に N と答えた後の HASP416・HASP417 の確認、チェックポイント再構成ダイアログ（$HASP272 は TERM のみ） |
| 操作に関係するが未対応のメッセージ | IEA338A・IEA341A（個別パラメーターの再指定）、IEA527A（SYSNAME 未指定）、IXC402D、$HASP490（ホットスタート拒否）、$HASP620（停止処理中のコマンド拒否）、$HASP098・$HASP070（JES2 異常時の終了オプション） |

### 使い方の制約

| 項目 | 備考 |
|---|---|
| 状態の保存 | 保存しない。ページを再読み込みすると最初からになる |
| 連携モードの条件 | 2つのタブが同じサイト（同じオリジン）にあるときだけつながる。ファイルをダブルクリックで開いた場合はつながらない |
| 連携中の jcl-terminal | SDSF の `/` コマンドとオペレーター演習は使えない（オペレーターの操作はシミュレータで行う） |
| 演習の「前のシフト」 | jcl-terminal から投入したジョブは含められない（挑戦の開始前は jcl-terminal がつながっていないため） |
| メッセージの言語 | コンソールのメッセージは英語（実機どおり）。解説は日本語 |
